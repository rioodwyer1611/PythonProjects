7. Consider the function f : Q ∩ [1, ∞) → Q ∩ [2, ∞) given by
f (x) = (x − 1)2 + 2 for all x ∈ Q ∩ [1, ∞).
(a) (4 marks) Prove that the function f is injective.
(b) (3 marks) Prove that the function f is not surjective.
• SOL a) Suppose that there are x1 , x2 ∈ Q ∩ [1, ∞) such that f (x1 ) = f (x2 ).
Then (x1 − 1)2 + 2 = (x2 − 1)2 + 2, so that (x1 − 1)2 = (x2 − 1)2 .
Since x1 − 1 and x2 − 1 are both non-negative, we conclude that x1 − 1 = x2 − 1, so that
x1 = x2 .
Thus, f is injective.
• SOL b) This question relies on the observation that the square root of a rational number is
not always rational.
