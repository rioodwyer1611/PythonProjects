Set Identities For all sets A, B and C that are subsets of a universal set U :
1. Commutative Laws
(a) A ∪ B = B ∪ A (b) A ∩ B = B ∩ A
2. Associative Laws
(a) (A ∪ B) ∪ C = A ∪ (B ∪ C)
(b) (A ∩ B) ∩ C = A ∩ (B ∩ C)
3. Distributive Laws
(a) A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
(b) A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
4. Identity Laws
(a) A ∪ ∅ = A (b) A ∩ U = A
5. Complement Laws
(a) A ∪ Ac = U (b) A ∩ Ac = ∅
6. Double Complement Law (Ac )c = A
7. Idempotent Laws

8. Universal Bound Laws
(a) A ∪ U = U (b) A ∩ ∅ = ∅

(a) (A ∪ B)c = Ac ∩ B c (b) (A ∩ B)c = Ac ∪ B c
10. Absorption Laws
(a) A ∪ (A ∩ B) = A (b) A ∩ (A ∪ B) = A

unique integers q and r such that n = dq + r and 0 ≤ r < d.
