(c) A ring of n binary cells has 2n possible configurations. The global rule ∆ is a deterministic function, so the sequence c(0) , c(1) = ∆(c(0) ), c(2) = ∆(c(1) ), . . . is fully determined
by c(0) .
By the pigeonhole principle, among the first 2n + 1 configurations in the sequence,
at least two must be identical. Once a configuration repeats, the entire subsequent
sequence repeats (since ∆ is deterministic), so the system has entered a cycle.
The maximum number of distinct configurations before a repeat is guaranteed is 2n .

Task 3. Fixed Points
Find all fixed-point configurations of Rule 30 on a ring of 4 cells, and determine which
ECA rules have the all-zeros configuration as a fixed point.

Solution.
(a) Rule 30: δ(l, c, r) = l ⊕ (c ∨ r). On a ring of 4, a fixed point (c0 , c1 , c2 , c3 ) satisfies:
δ(c3 , c0 , c1 ) = c0
δ(c0 , c1 , c2 ) = c1
δ(c1 , c2 , c3 ) = c2
δ(c2 , c3 , c0 ) = c3
With only 24 = 16 configurations, systematic checking is feasible. We verify the three
fixed points:
(0, 0, 0, 0): Every neighbourhood is (0, 0, 0), so δ = 0 ⊕ (0 ∨ 0) = 0. Each cell maps to
itself. ✓
(0, 1, 0, 1):
 δ(c3 , c0 , c1 ) = δ(1, 0, 1) = 1 ⊕ (0 ∨ 1) = 0 = c0 ✓
 δ(c0 , c1 , c2 ) = δ(0, 1, 0) = 0 ⊕ (1 ∨ 0) = 1 = c1 ✓
 δ(c1 , c2 , c3 ) = δ(1, 0, 1) = 0 = c2 ✓
 δ(c2 , c3 , c0 ) = δ(0, 1, 0) = 1 = c3 ✓

(1, 0, 1, 0): By symmetry with (0, 1, 0, 1) (both are alternating patterns, and the equations have the same cyclic structure):
 δ(0, 1, 0) = 1 = c0 ✓

All other configurations fail at least one equation. For example, (1, 1, 1, 1): δ(1, 1, 1) =
1 ⊕ (1 ∨ 1) = 0 ̸= 1.

(b) On the all-zeros configuration, every cell’s neighbourhood is (0, 0, 0). The fixed-point

This accounts for exactly 128 of the 256 ECA rules.

(b) The neighbourhood N has 9 entries (8 neighbours plus the cell itself), and each entry
is in Σ = {0, 1}. So the number of distinct input patterns to δ is |Σ||N | = 29 = 512.
A rule is a function that assigns an output (0 or 1) to each of these 512 input patterns. There are 2 choices per pattern, so the total number of distinct 2-state Mooreneighbourhood CAs is 2512 ≈ 1.3 × 10154 .
Compare with ECAs: an ECA neighbourhood has |N | = 3, giving 23 = 8 input patterns
and 28 = 256 rules. The jump from 8 input patterns to 512 makes the rule space explode
from 28 to 2512 .
(c) Wolfram classified all 256 ECA rules by running each one on many initial conditions and
observing the long-term behaviour. This was feasible because 256 is a small number.
For 2D Moore-neighbourhood CAs, there are 2512 possible rules. To put this in perspective: 2512 ≈ 10154 , which exceeds the number of atoms in the observable universe
(≈ 1080 ) by roughly 74 orders of magnitude. You cannot enumerate them, let alone
simulate and classify each one.
Even restricting to Life-like CAs (where the rule depends only on the neighbour count
and current state, as in B/S notation) gives 29 × 29 = 218 = 262,144 rules per neighbourhood type. This is tractable in principle but still vastly larger than 256.

Task 7. Decidability and Cellular Automata
Determine whether CELLt is decidable, and discuss whether a program could classify
arbitrary CAs into Wolfram classes.

Solution.
(a) Yes, CELLt is Turing-decidable.
Decider D: “On input ⟨R, c, i, t⟩:
1. Simulate ECA rule R on configuration c for exactly t steps.
2. Check whether cell i is in state 1 at time t.
3. If yes, accept. Otherwise, reject.”
Each simulation step updates every cell in constant time per cell, and there are exactly
t steps. The simulation always terminates, so D is a decider.
This parallels HALT2048 from the Week 7 worksheet: both are decidable because a
bounded simulation always terminates.
(b) No, such a program cannot exist for arbitrary CAs.
The fundamental difficulty is distinguishing Class III (chaotic) from Class IV (complex). A Class IV rule supports persistent interacting structures (“particles”) that can
implement computation. To determine whether a CA is Class IV, you would need to determine whether it supports universal computation, which requires answering a question
equivalent to the halting problem.
More precisely: if you could identify Class IV rules, you could identify Turing-complete
CAs, and hence determine which CAs have undecidable reachability problems. But this
is itself undecidable (by Rice’s theorem applied to the class of Turing-complete systems).
Classes I and II are easier to detect (fixed points and short cycles appear quickly), and
Class III can often be identified by statistical properties. The boundary between III
and IV is where decidability breaks down.
