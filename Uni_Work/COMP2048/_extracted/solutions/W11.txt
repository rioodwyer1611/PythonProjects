(c) How many queries does (b) need to solve this problem. Explain
why.
(c) Answer: We can read from the question (b) itself that it will take only
1 query. The signs ± do not matter since the probability of measuring an
outcome only depend on squared values |±|2 = 1 (Born rule). If the function
is constant, we measure 0 on the first qubit with 100% Born probability. If
the function is balanced, we measure 1 on the first qubit with 100% Born
probability.
