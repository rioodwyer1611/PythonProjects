Problem 2.

Pumping Lemma

Prove that the following language is not regular:
L = { 0i 1j | i ≤ j, i, j ≥ 0 }.

Solution.
Assume, for contradiction, that L is regular. Let p be the pumping length given by the
pumping lemma.
Choose the string s = 0p 1p . We have s ∈ L since p ≤ p, and |s| = 2p ≥ p.
By the pumping lemma, s = xyz with:
• |xy| ≤ p,
• |y| ≥ 1,
• xy k z ∈ L for all k ≥ 0.
Since |xy| ≤ p and s begins with p zeros, the substring y lies entirely within the prefix of
0’s. So y = 0m for some m ≥ 1.
Pump up: consider xy 2 z = 0p+m 1p . For this to belong to L, we would need p + m ≤ p,
i.e., m ≤ 0, contradicting m ≥ 1.
Therefore xy 2 z ∈
/ L, contradicting the pumping lemma. Hence L is not regular.

Why this works. The three-variable hierarchy E, T, F forces a fixed grouping in every parse
tree:
• E generates ∨-expressions whose operands are T ’s.
• T generates ∧-expressions whose operands are F ’s.
• F generates atoms or parenthesised expressions.
Because ∧ appears one level deeper in the grammar than ∨, every ∧ in a parse tree must occur
strictly below any ∨ that contains it. So ∧ groups its operands before ∨ does. The convention
is now baked into the structure of the grammar, not into a reading convention applied after
parsing.

L = { w c wR | w ∈ {a, b}∗ }

Problem 5.

Decidability

Prove that the complement of every Turing-decidable language is Turing-recognizable.

Solution.
Let L be a Turing-decidable language. By definition, there exists a Turing machine M
that decides L. That means that for every input w, the machine M halts and:
w ∈ L =⇒ M accepts w,
and
w∈
/ L =⇒ M rejects w.
We construct a Turing machine N that recognizes L, the complement of L.
On input w, the machine N does the following:
1. Run M on input w.
2. If M accepts w, then reject.
3. If M rejects w, then accept.
Since M is a decider, it halts on every input. Therefore, N also halts on every input.
Now consider any input w.

5

If w ∈ L, then w ∈
/ L. Since M decides L, M rejects w. Therefore, N accepts w.
If w ∈
/ L, then w ∈ L. Since M decides L, M accepts w. Therefore, N rejects w.
Thus N accepts exactly the strings in L. Hence L is Turing-recognizable.
Therefore, the complement of every Turing-decidable language is Turing-recognizable (also
Turing-decidable).

Problem 6.

Complexity Theory

For each statement below, say whether it is TRUE or FALSE. Briefly justify your answer.
(a) If A and B are two NP-complete languages, then A ≤p B and B ≤p A.
(b) If A is an NP-hard language, then A ∈
/ NP.
(c) The set of NP-complete languages would change if one measures time complexity
using multi-tape deterministic TMs instead of single-tape deterministic TMs.
(d) If P = NP, then there exists a deterministic TM that decides the Halting Problem in
polynomial time.

Solution.
(a) TRUE.
Since A and B are NP-complete, both are in NP and both are NP-hard. Because B is
NP-hard, every language in NP polynomial-time reduces to B. Since A ∈ NP, we have
A ≤p B.
Similarly, since A is NP-hard and B ∈ NP, we have
B ≤p A.
(b) FALSE.
An NP-hard language is not necessarily outside of NP. For example, SAT is NPcomplete, so it is NP-hard, but SAT ∈ NP. Thus an NP-hard language may or may
not be in NP.
(c) FALSE.
The set of NP-complete languages would not change. Single-tape and multi-tape deterministic Turing machines can simulate each other with only polynomial overhead.
Therefore, the class of polynomial-time computable reductions is the same under either
model, so the notion of NP-completeness does not change.
(d) FALSE.
