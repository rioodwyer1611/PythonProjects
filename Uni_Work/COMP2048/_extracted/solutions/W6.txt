(c) Algorithm.
The machine checks whether the number of 0’s is a power of 2.
It works as follows (from Sipser, Example 3.7):
M2 = “On input string w:
(i) Sweep left to right across the tape, crossing o# every other 0.
(ii) If in stage 1 the tape contained a single 0, accept.
(iii) If in stage 1 the tape contained more than a single 0 and the number of 0s was
odd, reject.

2

(iv) Return the head to the left-hand end of the tape.
(v) Go to stage 1.”
At the beginning, the first 0 is replaced with a blank to mark the leftmost cell of the
tape for our future right-to-left sweeps. Each iteration of stage 1 cuts the number of 0s
in half. As the machine sweeps across the tape in stage 1, it keeps track of whether the
number of 0s seen is even or odd. If that number is odd and greater than 1, the original
number of 0s in the input could not have been a power of 2. Therefore, the machine
rejects in this instance. However, if the number of 0s seen is 1, the original number must
have been a power of 2. So in this case, the machine accepts.
So the machine is repeatedly halving the number of surviving 0’s. It accepts exactly
when this repeated halving ends at 1, which happens exactly when the original length
is a power of 2.

Task 3.

Turing-recognizable vs. Turing-decidable

Explain why every Turing-decidable language is Turing-recognizable.

Solution.
A language is Turing-decidable if there exists a Turing machine that halts on every input
and accepts exactly the strings in the language.
A language is Turing-recognizable if there exists a Turing machine that accepts exactly the
strings in the language; on strings not in the language, it may either reject or loop forever.
Now suppose L is Turing-decidable. This means that there is a machine M such that:
• if w ↔ L, then M accepts w;

Turing Machines and Regular Languages

Let M = (Q, !, ε, q0 , F ) be a DFA.

(a) Construction.
Let the DFA be
M = (Q, !, ε, q0 , F ).
We construct a Turing machine

Q→ = Q ↗ {qacc , qrej },

like the DFA transition to ε(q, a) and moves right.

Why it works. After reading any prefix x of the input, the TM is in exactly the DFA
state that M would be in after processing x. Therefore, when it reaches the blank after

(b) A language is regular i# some DFA recognizes it. Given any DFA for a regular language,
the construction above produces a Turing machine that halts on every input and accepts

So for every regular language L, there exists a Turing machine that decides L. Hence
{regular languages} ↘ {Turing-decidable languages}.
In other words, every regular language is Turing-decidable.
