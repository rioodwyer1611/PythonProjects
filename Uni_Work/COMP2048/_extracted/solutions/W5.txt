Task 1. Derivations and Language of a Grammar
Consider the following CFG G over Σ = {a, b}:
S → aSb | aSbb | ε
(a) Derive the strings ab, abb, and aabbb using ⇒ notation. Show each substitution step.
(b) Draw the parse tree for your derivation of aabbb.
(c) Is the string abbb in L(G)? Is the string aabb in L(G)? Justify each answer by giving
a derivation or explaining why no derivation exists.
(d) Describe L(G) in set-builder notation, e.g. L(G) = { an bn | n ≥ 0 }.

Solution.
(a) Three derivations:
ab:
S ⇒ aSb ⇒ aεb = ab
abb:
S ⇒ aSbb ⇒ aεbb = abb
aabbb: We use S → aSbb first, then S → aSb, then S → ε:
S ⇒ aSbb ⇒ aaSbbb ⇒ aaεbbb = aabbb

(c) abbb: No, abbb ∈

Each rule application adds exactly one a and either one b (via S → aSb) or two b’s (via
S → aSbb). After n rule applications before the final S → ε, the string has n a’s and

(d) L(G) = { an bm | n ≤ m ≤ 2n, n ≥ 0 }.
Justification. Suppose a derivation uses the rule S → aSb exactly k1 times and S → aSbb
exactly k2 times (then terminates with S → ε). The resulting string has:
 n = k1 + k2 copies of a,
 m = k1 + 2k2 copies of b.

Since m = n + k2 and 0 ≤ k2 ≤ n, we get n ≤ m ≤ 2n.
Conversely, for any n ≤ m ≤ 2n, set k2 = m−n and k1 = 2n−m. Both are non-negative,
and k1 + k2 = n, so this is achievable.

Why every generated string is balanced : Each rule preserves the a/b balance. S → aSb
adds one a and one b. S → bSa adds one b and one a. S → SS concatenates two
balanced strings. S → ε produces the empty string (trivially balanced).
Why every balanced string is generated : By induction on string length. The empty
string is generated by S → ε. For a non-empty balanced string w: if w starts with a,
it must contain a matching b somewhere; one can show w can be decomposed as aSb
or SS for appropriate balanced substrings, each of which is generated by the induction
hypothesis.

consumed by the q4 self-loop. So the PDA accepts exactly when the number of b’s
exceeds the number of a’s by at least one.

Task 4. Designing a CFG
(a) Design a CFG that generates the language L = {an b2n | n ≥ 0}.
(b) Write a CFG that generates the same language as the regular expression 0∗1 (0 ∪ 1)∗ .
Hint: Start by describing in plain English what strings this regular expression matches.
(c) Is every regular language also context-free? Briefly explain why or why not.

6

Solution.
(a)
S → aSbb | ε
Each application of S → aSbb adds one a and two b’s. After n applications followed by
S → ε, the string is an b2n .
Verification:
 n = 0: S ⇒ ε. ✓
 n = 1: S ⇒ aSbb ⇒ aεbb = abb. ✓
 n = 2: S ⇒ aSbb ⇒ aaSbbbb ⇒ aaεbbbb = aabbbb. ✓

(b) The regular expression 0∗ 1(0 ∪ 1)∗ matches all binary strings that contain at least one
1. (The 0∗ matches any leading 0’s, 1 matches the first 1, and (0∪1)∗ matches everything
after.)
A CFG:
S → 0S | 1A

A → 0A | 1A | ε

S generates zero or more leading 0’s (via S → 0S), then produces a 1 and hands off to
A (via S → 1A). A generates any string over {0, 1} (via A → 0A | 1A | ε).
Verification:
 1: S ⇒ 1A ⇒ 1ε = 1. ✓
 01: S ⇒ 0S ⇒ 01A ⇒ 01. ✓
 110: S ⇒ 1A ⇒ 11A ⇒ 110A ⇒ 110. ✓
 0: S ⇒ 0S, but S always eventually needs S → 1A, so 0 cannot be generated. ✓

(c) Yes. Every regular language is also context-free.
A DFA is simply a PDA that never uses its stack. Since every regular language is
recognised by some DFA, and every DFA is a (trivial) PDA, every regular language
is recognised by some PDA. Since PDAs recognise exactly the context-free languages,
every regular language is context-free.
The containment is strict: {0n 1n | n ≥ 0} is context-free (we saw a CFG and PDA for
it in lecture) but not regular (by the pumping lemma).
