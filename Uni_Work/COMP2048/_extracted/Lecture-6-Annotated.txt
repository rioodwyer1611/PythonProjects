accept if M halts on w,
reject if M loops on w.

Now let’s build another TM that takes as input hMi, runs H on

loop

if H rejects hM,hMii,
if H accepts hM, hMii.

Now let’s see what happens if we run D on hDi (i.e., on its encoding!):
If H says D halts on hDi then, by construction, D must loop!
If H says D loops on hDi then, by construction, D must halt!
Contradiction! Therefore the decider H cannot exist!
