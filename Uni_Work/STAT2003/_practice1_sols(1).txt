Question 5. [10 marks]
Consider the following Python program:
def simulate():
u1 = random()
if u1 < 0.4:
u2 = random()
if u2 < 0.5:
return 0
else:
return 1
else:
u2 = random()
count = 0
while u2 >= 0.3 and count < 3:
count += 1
u2 = random()
return count
Let X be the value returned by simulate().
(a) Carefully determine the PMF of X. (Hint: consider cases A and B separately, noting that case B
generates a truncated geometric-like count.)
[3 marks]
(b) Compute E[X] and Var(X).
[3 marks]
(c) Find the probability generating function GX(s) = E[sX] of X, and confirm that G′
X(1) = E[X].
[4 marks]
Note about Python: random() generates a U(0, 1) random variable.
Solution:
(a) Case A (probability 0.4): returns 0 with probability 0.5, returns 1 with probability 0.5.
Case B (probability 0.6): The variable count starts at 0 and increases by 1 each iteration of the
while loop. The loop continues while u2 ≥ 0.3 and count < 3. Each new u2 is drawn inde-
pendently, so at each iteration, the loop exits with probability 0.3 or continues with probability
0.7.
• P(return 0 | B): first u2 < 0.3, probability = 0.3.
• P(return 1 | B): first u2 ≥ 0.3, then new u2 < 0.3, probability = 0.7 × 0.3 = 0.21.
• P(return 2 | B): two continues then exit, probability = 0.72 × 0.3 = 0.147.
• P(return 3 | B): three continues (loop exits since count = 3), probability = 0.73 = 0.343.
