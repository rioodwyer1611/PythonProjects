# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This is a personal data science learning portfolio containing multiple standalone Python projects. The repository combines:
1. **Portfolio website** - Static HTML site generated from README.md and deployed via Netlify
2. **Learning projects** - IBM Data Science Professional Certificate coursework and personal experiments
3. **Job application tool** - Streamlit dashboard for job searching with web scrapers
4. **University work** - Computer Science/Data Science coursework (UQ)
5. **Building_An_LLM** - Custom LLM implementation from scratch (tokenization, transformers, training)

## Build Commands

### Portfolio Website (Netlify)
```bash
# Generate index.html from README.md
node build.js

# The site is deployed via Netlify (netlify.toml configured)
```

### Running Individual Projects

Most Python scripts are standalone and can be run directly:
```bash
# General Python script
python Learning_Data_Science/<Project>/<script>.py

# Streamlit dashboard (Over_Employed_Project)
streamlit run Over_Employed_Project/main.py

# Jupyter notebooks
jupyter notebook Learning_Data_Science/Basic_Jupyter_Notebook/basic_jupyter_notebook.ipynb
jupyter notebook Neurotech_Club_Work/MNE_tut.ipynb
```

### PyTorch Projects
```bash
# PyTorch scripts download datasets automatically on first run
python Learning_Data_Science/PyTorch/quickstart.py

# Building_An_LLM training (see Building_An_LLM/README.md for full pipeline)
python Building_An_LLM/train.py
```

### Key Patterns

1. **No package management**: No requirements.txt or pyproject.toml. Each script documents its dependencies in comments at the top (e.g., `# !pip install yfinance`).

2. **Self-documenting scripts**: Each Python file is standalone and typically follows this structure:
   - Commented pip install commands
   - Imports
   - Function definitions
   - Sequential execution (not wrapped in `if __name__ == "__main__"`)

3. **Data files**: Large CSVs and model files (.pth) are committed to the repo (not gitignored). This is intentional for portfolio portability.

4. **Generated HTML**: Several large `report_*.html` files in Neurotech_Club_Work/ are generated by MNE-Python analysis tools.

### Build System

The `build.js` Node script parses `README.md` to generate `index.html`:
- Extracts personal info (name, bio, details) from "## About Me" section
- Parses "## [Project Name](url)" sections into project cards
- Generates tech tags from list items
- Outputs static HTML with embedded CSS

Edit `README.md` to update portfolio content, then run `node build.js` to regenerate.
